# 🖥️ Cpp

## 🧩 Overview

The **Cpp** project is part of the 42 curriculum and consists of a series of C++ exercises designed to strengthen understanding of **object-oriented programming**, **C++ standard library**, and **core language concepts**.

Through this project, students learn to implement classes, handle memory management, and apply C++ best practices in small but progressively complex programs.

## 🧱 Project Goals

- Understand **C++ syntax** and programming paradigms.  
- Implement **classes**, **constructors**, **destructors**, and **methods**.  
- Use **encapsulation, inheritance, and polymorphism**.  
- Apply **operator overloading** for custom types.  
- Manage dynamic memory with **pointers**, **new/delete**, and **RAII** principles.  
- Use **C++ Standard Library** features like vectors, strings, and streams.

## ⚙️ Implemented Exercises

| Exercise | Description |
|----------|-------------|
| cpp00 | Basic class implementation and constructors |
| cpp01 | Copy constructors, assignment operators, and destructors |
| cpp02 | Inheritance and polymorphism examples |
| cpp03 | Operator overloading for custom types |
| cpp04 | Abstract classes and pure virtual functions |
| cpp05 | Templates and generic programming |
| cpp06 | Exception handling and error management |
| cpp07 | File I/O and stream management |
| cpp08 | STL containers and algorithms |
| cpp09 | Advanced project combining multiple C++ concepts |

## 🧠 Concepts Learned

Through this project, I learned how to:  
- Properly define and manage **classes and objects** in C++.  
- Apply **RAII** and manage dynamic memory safely.  
- Use **inheritance** and **polymorphism** to extend functionality.  
- Implement **operator overloading** to simplify code readability.  
- Work with the **Standard Template Library (STL)** for data structures and algorithms.  
- Handle exceptions and ensure robust error management.
